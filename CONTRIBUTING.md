# Contributing to Team Task Manager

First off, thank you for considering contributing to Team Task Manager! It's people like you that make it such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our issue tracker.

## Setting up your environment

1. Fork the repo and create your branch from `main`.
2. Follow the setup instructions in the `README.md` to get the frontend and backend running locally.
3. Ensure your code adheres to our styling guidelines.

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, if applicable.
3. Once you submit a PR, it will be reviewed by the maintainers.
